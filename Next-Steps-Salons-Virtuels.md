# Étapes suivantes – Salons Virtuels

## 1. Ce que tu peux faire maintenant sans attendre les dépendances

### A. Finaliser la définition du MVP
- garder uniquement les fonctionnalités essentielles de la V1
- éviter les fonctionnalités non prioritaires pour l’instant

### B. Préparer la structure technique de base
- créer les dossiers backend et frontend
- définir les routes principales
- préparer les modèles de données de base

### C. Écrire les premières tâches techniques
- créer un salon
- lister les salons
- créer un stand
- lister les stands d’un salon
- créer un rendez-vous
- changer le statut d’un rendez-vous

## 2. Ce que tu peux déjà implémenter seul

### Backend
- endpoint pour créer un salon
- endpoint pour lister les salons
- endpoint pour créer un stand
- endpoint pour lister les stands d’un salon
- endpoint pour créer un rendez-vous

### Frontend
- page liste des salons
- page détail d’un salon
- page formulaire de stand
- page formulaire de rendez-vous
- page tableau de bord admin simple

## 3. Ce qu’il faut éviter pour l’instant
- intégration réelle avec Stripe
- validation complète du profil exportateur
- logique de paiement complexe
- upload de fichiers avancé si ce n’est pas déjà prêt

## 4. Plan de travail simple pour commencer

### Jour 1
- préparer les dossiers du projet
- définir les modèles de base
- créer la structure backend

### Jour 2
- implémenter la création et la lecture des salons
- implémenter la création et la lecture des stands

### Jour 3
- implémenter la création des rendez-vous
- créer les pages frontend de base

### Jour 4
- tester le parcours simple
- corriger les bugs
- préparer la version de démonstration

## 5. Ce que tu dois dire à l’équipe

Tu peux leur dire :
- “Nous avons déjà défini le périmètre, les user stories, les entités, les statuts et les premières APIs.”
- “Je peux déjà commencer la base technique du module même si certaines dépendances externes ne sont pas encore reçues.”

## 6. Résumé

Tu n’attends pas les dépendances pour commencer la préparation technique. Tu peux déjà construire une version simple et fonctionnelle du module, puis l’adapter plus tard selon les informations reçues des autres stagiaires.
